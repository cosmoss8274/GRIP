NeoDesign: A Computational Platform for TCR-pMHC Interaction Prediction and De-novo Pepide Design

NeoDesign is a comprehensive computational toolkit for TCR-pMHC interaction prediction, peptide engineering, and de novo neoantigen design. It provides a unified framework for modeling the complex interplay between T-cell receptors (TCRs) and peptide-MHC complexes, enabling advances in immunotherapy, vaccine design, and personalized medicine.
