# NeoDesign: A Computational Platform for TCR-pMHC Interaction Prediction and De-novo Peptide Design

NeoDesign is a computational toolkit for TCR-pMHC interaction prediction, peptide engineering, and de novo design. It provides a unified framework for modeling the interplay between T-cell receptors (TCRs) and/or peptide-MHC complexes, applicable and advancing fields like experimental peptide screening and vaccine design.
